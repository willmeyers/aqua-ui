  <button value="list"   icon="list"   label="List view"></button>
</aqua-button-group>
import { AquaButtonGroup } from "@aqua-ui/react";

<AquaButtonGroup value={view} label="View"
                 onChange={(e) => setView(e.detail.value as string)}>
  <button value="icon" icon="icon" label="Icon view"></button>
  <button value="list" icon="list" label="List view"></button>
</AquaButtonGroup>
Props & Events
valuethe chosen segment; a space-separated list when multiple (the values property reads it as an array)
labelaccessible name for the group
multipletoggle group instead of single-select
momentaryplain buttons, no sticky state
iconsforce the compact icon sizing (automatic when every segment is an icon)
disableddisables every segment
inactivedesaturates the selected segment, as an unfocused window did
Segment children
value · label · disabledper-segment; label becomes the accessible name for icon segments
icon · srcone of the three original view glyphs, or your own image
Events
changedetail.value: the selection (array when multiple)
commanddetail.value: the pressed segment, in momentary mode
keyboardone tab stop; arrows, Home and End move the selection
