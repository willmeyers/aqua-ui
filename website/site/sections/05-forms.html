Props & Events
all of themform-associated: they submit, reset and validate like native inputs, and fire change / input with detail.value
aqua-checkbox · aqua-radio
checked · indeterminate · disabledstate; radios with the same name uncheck each other
name · valuewhat submits (value defaults to on); children are the label
aqua-field
labelstacks a label above the input
typetext (default), search, textarea (with rows), or any input type
value · placeholder · readonly · disabled · nameas on a native input
aqua-select
label · value · disabled · namechildren are <option>s; the options property replaces them from script
popuppops over its button with the current choice under the pointer, which no native <select> reproduces
aqua-slider
min · max · step · valuenumeric range, as on a native range input
tickstick count; ticks give the pentagon thumb
roundthe glossy round thumb
aqua-stepper
value · min · max · stepthe number it steps
fieldshows the editable text box beside the arrows
wrapwraps at the ends instead of clamping
press and holdrepeats, accelerating once, as the real one did
